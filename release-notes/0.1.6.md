- **Hidden `pizlonatedFIP<sig>_*` implementation symbols (`llvm/09-filc-hidden-fip-symbols.patch`):** Marks non-local `pizlonatedFIP<sig>_*` function implementations `STV_HIDDEN` after `PutImplIntoComdat` in `FilPizlonator` so each shared library's local `pizlonatedFO_*` `FunctionObject` resolves via a relative relocation instead of being interposed across `RTLD_GLOBAL` DSOs on musl (which lacks `RTLD_DEEPBIND`), while preserving exported `pizlonatedFI<sig>_*` aliases and `pizlonated_*` getters. Fixes `dlsym(handle, ...)` dispatch for plugin systems sharing identical entrypoints (such as PHP shared extensions exporting `get_module`); downstream shared libraries and extensions built with `0.1.6` no longer require the `-Wl,-Bsymbolic-functions` linker workaround (which remains harmless where already configured). Being submitted upstream to Fil-C.
- **RTLD_GLOBAL duplicate-export regression test (`scripts/test-toolchain` `TEST (l)`):** Compiles two independent shared libraries exporting identical fast-call and variadic symbols without `-Wl,-Bsymbolic-functions`, loads both with `dlopen(..., RTLD_LAZY | RTLD_GLOBAL)`, and verifies both runtime `dlsym(ha/hb, ...)` isolation and ELF symbol/relocation invariants (`llvm-nm -D` and `readelf -rW`: no exported or preemptible `pizlonatedFIP` symbols, with `pizlonated_*` and `pizlonatedFI*` exports preserved).
